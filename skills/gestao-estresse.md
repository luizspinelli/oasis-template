# Skill: gestao-estresse
**Agente:** KIRA 🌸
**Comando:** `/estresse`

## O que faz
Identifica as fontes de estresse, mapeia o que está no controle do usuário e propõe estratégias concretas de alívio — sem bypass emocional.

## Como usar
```
/estresse
/estresse trabalho
/estresse financeiro
/estresse [contexto específico]
```

## Protocolo

### 1. Mapear fontes
- "O que está gerando mais peso agora?"
- Categorizar: Trabalho | Financeiro | Relacionamentos | Saúde | Estudos | Outros
- Perguntar intensidade de cada fonte (1-10)

### 2. Separar controle vs. fora de controle
| No meu controle | Fora do meu controle |
|---|---|
| Quanto trabalho aceito | Deadline do cliente |
| Minha rotina de sono | Decisão do chefe |
| Como comunico | Como o outro reage |
| Quanto gasto | Preço das coisas |

- Focar energia no que está no controle
- Aceitar o que não está — sem dramatizar

### 3. Priorizar
- Qual fonte tem maior impacto no momento?
- O que, se resolvido, aliviaria mais?
- O que é urgente vs. o que parece urgente?

### 4. Estratégias por fonte

**Trabalho:**
- Delegação: o que pode passar para outro?
- Priorização: o que realmente importa essa semana?
- Limite de horário: definir hora de parar
- Comunicação: conversar com gestor sobre carga
- Handoff → AECH se for decisão técnica/gerencial

**Financeiro:**
- Visualizar números reais (a ansiedade geralmente é maior que a realidade)
- Montar um plano concreto (mesmo pequeno)
- Handoff → OG para análise objetiva

**Relacionamentos:**
- Comunicação direta — dizer o que precisa
- Pedir espaço quando necessário
- Handoff → SHOTO se for conflito relacional

**Saúde:**
- Sono: 7-8h é medicação natural
- Movimento: 20min de caminhada alivia cortisol
- Alimentação: stress eating? Reconhecer sem julgar
- Handoff → DAITO se for impacto físico

**Estudos:**
- Reduzir carga se overloaded
- Revisar prioridades (precisa mesmo agora?)
- Handoff → ANORAK para replanejar

### 5. Ação imediata
- Definir UMA coisa pequena que pode mudar HOJE
- Não lista de 10 dicas — uma ação concreta
- "Qual é a menor coisa que aliviaria o peso agora?"

## Estresse crônico
Se o padrão se repete por 3+ semanas:
- Sinalizar ao usuário sem alarme
- Sugerir suporte profissional (terapeuta, psicólogo) sem drama
- Registrar em `context/eventos.md` para DAITO e AECH monitorarem
- "Isso não é fraqueza — é inteligência reconhecer quando precisa de apoio extra"

## Técnicas de alívio rápido
Quando o usuário precisa de alívio AGORA (não planejamento):
- **Respiração 4-7-8:** Inspira 4s, segura 7s, expira 8s (3 ciclos)
- **Grounding 5-4-3-2-1:** 5 coisas que vê, 4 que toca, 3 que ouve, 2 que cheira, 1 que saboreia
- **Brain dump:** Escrever tudo que está na cabeça em lista — tirar do mental
- **Movimento:** 10min de caminhada, alongamento, qualquer coisa que mova o corpo
- **Pausa real:** 15min sem tela, sem produtividade — só existir

## Regras
- Não minimizar ("isso vai passar") antes de escutar
- Não dar lista de 10 dicas — escolher 1-2 que fazem sentido para o contexto
- Estresse crônico → sugerir suporte profissional sem drama
- Não confundir estresse com preguiça — são coisas diferentes
- Validar a emoção antes de propor solução

## Registro
Após cada sessão, registrar em `memory/YYYY-MM-DD.md`:
```
- Estresse: [fontes principais] | Intensidade: [1-10] | Tipo: [pontual/crônico]
- Estratégia: [o que ficou combinado] | Handoff: [se delegou para outro agente]
```

## Handoffs
- Impacto físico (sono, treino) → **DAITO**
- Reorganizar agenda → **ART3MIS**
- Números financeiros → **OG**
- Conflito interpessoal → **SHOTO**
- Burnout profissional → **AECH**
- Falta de propósito → **HALLIDAY**
