# Contribuindo com o OASIS

Obrigado pelo interesse! O OASIS é um projeto open source e contribuições são bem-vindas.

## Como contribuir

### 🐛 Reportar um bug
Abra uma [Issue](https://github.com/SEU-USUARIO/oasis-template/issues) com:
- O que aconteceu
- O que era esperado
- Passos para reproduzir

### 💡 Sugerir uma melhoria
Abra uma [Issue](https://github.com/SEU-USUARIO/oasis-template/issues) com a tag `enhancement`.

### 🔧 Pull Request
1. Fork o repositório
2. Crie uma branch: `git checkout -b minha-feature`
3. Faça suas alterações
4. Commit: `git commit -m "feat: descrição"`
5. Push: `git push origin minha-feature`
6. Abra um Pull Request

## O que contribuir

- **Novos agentes** — ex: MARCO (jurídico), SOFIA (nutrição), PEDRO (produtividade)
- **Integrações** — Google Calendar, Notion, Spotify, Garmin, Strava
- **Exemplos de canais** — templates de `channels/*.md` para casos de uso comuns
- **Traduções** — inglês, espanhol
- **Documentação** — melhorias no README, guias, tutoriais

## Padrões

- Português do Brasil nos agentes e documentação em pt-BR
- Sem dados pessoais em nenhum arquivo
- Agentes devem ter: persona clara, especialidades, tom definido, seção "Como Configurar"
- Scripts Node.js com comentários em português
